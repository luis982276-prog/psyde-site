PSYDE Admin

Arquivo principal: admin/index.html
Rota pretendida: /admin

O painel usa o Supabase do projeto PSYDE para login, produtos e imagens.
O login precisa estar cadastrado em auth.users e também em public.admin_users.

Para colocar na Vercel, copie a pasta admin para a raiz do projeto publicado e faça um novo deploy.
